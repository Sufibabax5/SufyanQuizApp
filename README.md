
Quiz App

An interactive quiz application built using HTML, CSS, and JavaScript as part of my web development training at Saylani Mass IT Training (SMIT).

Technologies Used
- HTML5
- CSS3
- JavaScript

 Features
- Multiple-choice questions with interactive answer selection
- Score calculation based on correct answers
- Responsive design (works on mobile and desktop)
- Clean and user-friendly interface

 What I Learned
This project helped me strengthen my understanding of DOM manipulation, JavaScript event handling, and managing dynamic content with logic-based functionality.
